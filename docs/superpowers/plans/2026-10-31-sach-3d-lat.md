# Sách 3D lật – Kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Mục tiêu:** Thêm trang `/sach/` để lật sách bằng ảnh từng trang. Kèm theo: lệnh nhập PDF hoặc ảnh, mục lục, link có số trang, hai bộ ngôn ngữ, SEO và mã QR.

**Kiến trúc:**
- Trang Vite thứ hai `sach/index.html` chạy `src/book/main.ts`, bundle riêng không kèm Three.js.
- Trang dùng chung `schema.ts`, `i18n`, `ui/` (topbar, panel, styles) với triển lãm.
- Lật trang bằng `page-flip` ở chế độ HTML. Lớp `BookView` tự tính khổ sách cho vừa màn hình và chỉ tải ảnh quanh trang đang đọc.
- Nội dung nằm trong `public/content/book.json`. Phía build (`read-content`, `build-pages`, `gen-qr`, `gen-placeholders`) đọc thêm sách.

**Công nghệ:**
- TypeScript, Vite 6, zod 3, `page-flip@2.0.7`.
- `pdfjs-dist@6.4.299` (chỉ dùng trong script), `@napi-rs/canvas`.
- vitest, Playwright.

Thiết kế: `docs/superpowers/specs/2026-10-31-sach-3d-lat-design.md`.

**Lưu ý:**
- `page-flip` không kèm kiểu TypeScript, nên import `page-flip/dist/js/page-flip.module.js` qua file khai báo tự viết.
- `PageFlip.destroy()` gỡ luôn phần tử khối, nên phải dựng khối mới khi đổi chế độ.
- `autoSize` đặt `width: 100%` lên khối, nên đặt bề ngang lên khung bọc `.book-frame`.

```ts
import { clamp } from '../util/math';

export const BOOK_PATH = '/sach/';

/** Ảnh thu nhỏ của một trang: cùng tên, trong thư mục con nho/. */
export function thumbOf(page: string): string {
  const i = page.lastIndexOf('/');
  return `${page.slice(0, i)}/nho/${page.slice(i + 1)}`;
}

/** Các trang đang mở (chỉ số từ 0). Bìa đứng riêng, sau đó từng cặp (1, 2), (3, 4)…; trang cuối lẻ đứng riêng. */
export function spreadOf(index: number, count: number, twoPage: boolean): number[] {
  const i = clamp(Math.round(index), 0, count - 1);
  if (!twoPage || i === 0) return [i];
  const start = i % 2 === 1 ? i : i - 1;
  return start + 1 < count ? [start, start + 1] : [start];
}

/** Nhãn số trang đang mở, đánh từ 1: "5" hoặc "2–3". */
export function pageLabel(index: number, count: number, twoPage: boolean): string {
  return spreadOf(index, count, twoPage).map((i) => i + 1).join('–');
}

/** `?trang=N` → chỉ số trang (từ 0), kẹp trong sách; thiếu hoặc sai thì trang đầu. */
export function parsePageParam(search: string, count: number): number {
  const raw = new URLSearchParams(search).get('trang');
  if (!raw || !/^\d+$/.test(raw)) return 0;
  return clamp(Number(raw), 1, count) - 1;
}

export function bookPath(index: number): string {
  return index > 0 ? `${BOOK_PATH}?trang=${index + 1}` : BOOK_PATH;
}

export interface BookLayout {
  twoPage: boolean;
  pageWidth: number;
  blockWidth: number;
}

/** Hiện hai trang khi trang không nhỏ đi quá 15% so với hiện một trang; `ratio` = rộng/cao của trang. */
export function chooseLayout(width: number, height: number, ratio: number): BookLayout {
  const one = Math.min(width, height * ratio);
  const two = Math.min(width / 2, height * ratio);
  const twoPage = two >= 0.85 * one;
  const pageWidth = Math.max(1, Math.floor(twoPage ? two : one));
  return { twoPage, pageWidth, blockWidth: twoPage ? pageWidth * 2 : pageWidth };
}
```
